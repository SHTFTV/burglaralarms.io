Installation

Get ready for alarm installation day

Prepare permissions, account access and a supervised handover before the installer leaves.

Confirm who can approve the work

Renters and property managers should confirm the relevant permissions before any permanent mounting or wiring. Make someone available to show the installer the property and agree who can approve changes to the installation scope.

Set up owner-controlled access

Ask the installer to show the account owner how to add and remove authorized people. Use individual access where the equipment supports it and set up multifactor authentication if offered. Keep account recovery and service contact details somewhere the authorized owner can find them.

Arrange a supervised handover

Ask the technician to coordinate any necessary test mode with the monitoring centre before testing. Have the technician demonstrate normal use, check agreed notifications and explain the difference between an alert, a service reminder and a device trouble message.

Keep records for the next service visit

Save the equipment inventory, manuals and provider contacts. Ask which maintenance and testing intervals apply to your equipment and who should be contacted before retesting. Update account permissions when occupancy or building responsibility changes.
